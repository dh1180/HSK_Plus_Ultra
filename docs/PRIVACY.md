# HSK Plus Ultra 개인정보 안내

적용 버전: 0.2.0 / 작성일: 2026-11-05

HSK Plus Ultra는 계정 없이 사용하는 단어 학습 앱입니다. 앱은 이름, 이메일, 위치, 연락처를 요청하지 않습니다. 자체 서버, 광고, 추적 SDK, 사용 분석 SDK를 통해 학습 기록을 수집하거나 전송하지 않습니다.

## 기기에 저장하는 정보

단어별 학습 단계, 다음 복습 시각, 마지막 학습 시각, 응답 횟수, 한 번에 학습할 단어 수와 진행 중인 학습을 앱 저장소에 보관합니다. 앱을 삭제하면 기록이 사라질 수 있습니다. ‘설정 → 학습 기록 초기화’에서 앱이 관리하는 현재 및 이전 버전의 학습 기록을 삭제할 수 있습니다.

## 백업과 복원

사용자가 직접 JSON 파일을 내보내고 불러옵니다. 내보낸 파일에는 학습 이력이 들어 있습니다. 공유 대상으로 선택한 파일 앱, 클라우드 저장소 등의 보관 정책은 해당 제공자에게 적용됩니다. 앱 초기화가 사용자가 내보낸 파일까지 삭제하지는 않습니다. 운영체제의 백업·동기화 정책도 별도로 적용될 수 있습니다. Android의 자동 앱 백업은 앱 설정에서 비활성화했습니다.

## 음성 및 외부 링크

중국어 발음은 운영체제의 TTS 엔진으로 제공합니다. 음성 엔진은 설정과 제공자에 따라 네트워크를 사용할 수 있습니다. 앱 자체의 서버에는 전송하지 않습니다. 외부 문의·출처 링크를 열면 웹브라우저와 해당 사이트의 정책이 적용됩니다.
