# 프로젝트 종합 점검 — 2026-09-19

대상: `dh1180/HSK_Plus_Ultra`, 기준 커밋 `7d82670`.

## 판단

앱의 기본 구조는 소규모 로컬 학습 앱에 적합하다. 다만 **한국어 역매핑 뜻과 기계 번역 예문을 검수 완료 자료처럼 제공하던 점은 학습용 배포를 막아야 할 수준의 문제**였다. 이 수정은 확인된 오류를 교정하고, 미검수 내용이 학습 기록으로 확정되지 않도록 구분한다. 5,400개 전체의 언어적 정확성을 보증한 것은 아니다.

## 구조

- Expo / React Native / TypeScript. 서버·로그인·클라우드 동기화는 없다.
- `App.tsx`: 급수 선택, 세션 큐, 응답 및 화면 전환.
- `src/screens/`: 홈, 급수·목록, 단어 카드, 결과 화면.
- `src/lib/srs.ts`: 복습 단계와 예약 시각. `study.ts`: 복습 우선 큐.
- `src/lib/storage.ts`, `progress.ts`: 로컬 저장, 유효성 검사, 순차 쓰기.
- `src/data/vocabulary.ts`: 메타데이터·프로젝트 작성 뜻·교정 항목을 조합하는 런타임 경계.
- `content-overrides.json`: ID, 표제어, 병음을 함께 고정한 뜻·예문 교정.
- 생성 스크립트/작업: 후보 생성. 런타임으로 자동 승격하지 않는다.

파일 수에 비해 별도 서버나 과도한 상태관리 라이브러리는 필요하지 않다. 향후 중단 세션 복원·클라우드 동기화를 도입하면 세션 상태를 reducer와 별도 저장 모델로 분리하는 것이 적절하다.

| 급수 | 전체 | 표시 예문 | 뜻 검토 대기 |

| 3 | 500 | 15 | 473 |

| 6 | 1,800 | 30 | 1,758 |
| 합계 | 5,400 | 605 | 4,748 |

- 뜻 검토 대기 4,748개는 **오류로 확정한 개수**가 아니다. 잘못된 매핑이 다수 확인된 파이프라인의 미검수 항목 수다.
- 자동 학습 가능: 652개(1급 300 + 2급 200 + 상위 급수 교정 105 + 기존 프로젝트 작성 뜻 47).
- 자동 생성 예문 4,795개는 숨기며 원본 후보 파일은 보존한다.
- 모든 단어는 검색할 수 있다. 미검수 뜻 카드에서는 판정을 막아 기존 SRS 기록을 변경하지 않는다.
- 기존 학습 기록은 삭제하지 않는다. 미검수 단어의 예약도 보존하되 교정 전까지 자동 큐에서는 제외한다.
- 1급은 기존 프로젝트 작성 문장이다. 305개 교정은 AI 보조 편집 결과이며, 독립된 중국어 교사 검수 완료를 의미하지 않는다.
- 기계 생성 후보에서 64개 동형 표제어 묶음과 서로 다른 중국어 문장 5개 이상에 재사용된 한국어 번역 묶음 40개를 찾았다. 이것만으로 각 문장이 틀렸다고 확정하지는 않는다.

상세 기계 판독 결과: `data/content-audit.json`. `npm run audit:content -- --write`로 재생성한다.

## 검증 범위

- TypeScript 정적 검사.
- 모든 SRS 단계 전이, 복습 시간 경계, 재출제 성공/실패, 오래된 복습 우선순위.
- 손상된 저장값, 순차 저장과 실패 후 복구, 전체 범위 검색, 다의어 교정 회귀 검사.
- 모든 5,400개 런타임 항목의 개수·ID·뜻·병음·예문 연결 및 미검수 후보 노출 차단 검사.
- Expo 웹 export 성공. Chromium 138로 검색·재출제·집계·저장 복원·오류 복구·미검수 열람·페이지 분할·320/390/768/1440px 화면을 확인했다. 기본 Playwright 브라우저 다운로드는 네트워크 오류가 있어 로컬 Chromium 실행 파일을 사용했다.
- `npm audit --omit=dev`: moderate 10개(Expo → xcode → uuid 전이 경로), high/critical 0개. 자동 제안은 Expo 46으로의 비호환 변경이라 적용하지 않았다. 빌드 도구 의존성 업데이트와 네이티브 빌드 검증을 함께 수행해야 한다.
- 외부 코퍼스·번역 모델을 다시 다운로드하는 전체 생성 작업은 재실행하지 않았다. 생성기 문법 및 오프라인 단위 검사를 수행했다.
- 실제 Android/iOS 설치·OS TTS 발음·기기별 안전 영역은 실기기 검증이 필요하다. 웹 검증으로 대체됐다고 주장하지 않는다.

## 남은 과제

1. **출시 전**: 3~6급 미검수 뜻과 예문을 중국어 교육 경험자가 검토. 자동 생성 모델을 교체해도 검수 없이 배포하지 않는다.
2. 단어 단독 TTS는 `还/行/长/得` 등의 문맥별 독음을 보장하지 않는다. 교정 병음과 대조하고 장기적으로 검증된 음원을 연결한다.
3. HSK 표제어의 공식 기준은 외부 구조화 자료가 원천 대강을 재정리한 것이다. 앱 자체가 공식 인증 앱이거나 한국어 뜻·예문이 공식 자료인 것은 아니다.
4. 앱 삭제·기기 분실 시 복구할 계정/백업 기능은 없다. 저장 실패는 안내하지만 영구 백업을 제공하지 않는다.
5. 새 단어 KNOWN → 장기 기억은 기존 제품 정책을 유지했다. 기억 능력을 객관적으로 검증한 결과는 아니다.
6. ‘한 번에 학습할 단어 수’는 세션 크기다. 날짜별 상한·연속 학습 일수 기능은 구현하지 않았다.
